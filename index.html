AUTO UPDATE每天自动更新是怎么实现的

网站是纯静态的，数据以 JS 文件形式存放，因此不需要数据库和后端：脚本每次运行重写数据文件，页面下次打开就是最新的。可以本地双击打开，也可以部署到任意静态托管。

STEP 01

抓取

并发拉取 15 个中英文 AI 新闻 RSS / Atom 源，全部使用 Python 标准库，无需安装第三方依赖。

STEP 02

清洗

AI 相关性过滤、正文去标签、时间统一到北京时间、按链接与标题去重，并按关键词自动归入 8 个分类（含「优惠福利」）。

STEP 03

归档

与历史数据合并，按日期分组生成当日要点，保留天数由配置决定，写入 data/news.js 与 data/news.json（脚本以后者为历史基准）。

STEP 04

发布

GitHub Actions 每天定时运行并提交数据变更，GitHub Pages 自动发布；也可用本地 cron 或手动触发。

方式一 · GitHub Actions（推荐，全自动）

把整个目录推到 GitHub 仓库，开启 Pages 后每天自动更新，电脑关机也不影响。
# 仓库已包含 .github/workflows/daily.yml # 每天北京时间 08:30 与 20:30 各跑一次 git init && git add . && git commit -m "init" git remote add origin <你的仓库地址> git push -u origin main # Settings → Pages → Source: main / root

方式二 · 本地定时任务

在自己机器或服务器上每天固定时间刷新数据文件。
# 手动跑一次 python3 scripts/daily_update.py # 或用封装脚本 bash scripts/run_daily.sh # crontab -e 添加（每天 08:30） 30 8 * * * cd /workspace && \ bash scripts/run_daily.sh >> update.log 2>&1

目录结构

改数据不用改页面，页面永远从数据文件渲染。
index.html # 页面骨架 assets/style.css # 样式 assets/app.js # 渲染 / 搜索 / 图表 data/base.js # 模型·产品·智能体·编程器（人工校订） data/news.js # 每日新闻（脚本自动写入） data/news.json # 同内容 JSON，供其他程序消费 data/deals.js # 平台优惠福利（人工校订） scripts/sources.json # 新闻源与分类关键词配置 scripts/daily_update.py # 采集主脚本 scripts/run_daily.sh # 定时入口 .github/workflows/ # 每日自动更新流水线

怎么扩展

三处可配置，不需要动前端代码。

加新闻源：编辑 scripts/sources.json 的 feeds 数组，填 name / url / lang 即可。
改分类规则：编辑同文件的 categories 关键词表，脚本按标题关键词打标签；含「优惠福利」类，命中的新闻会自动出现在福利线索里。
改AI过滤词：编辑 keywords，决定哪些条目算 AI 新闻。
改保留天数：scripts/sources.json 的 settings.keepDays（默认 60），也可运行时用 --days N 覆盖。
换基准数据：直接编辑 data/base.js，脚本不会覆盖它。
改优惠活动：编辑 data/deals.js，填 deadline 后页面自动算倒计时并标记过期。

提示：RSS 抓取受源站限流影响，脚本对单个源失败做了容错，不会中断整体更新；若某天全部失败或历史数据文件损坏，脚本会以失败状态退出，Actions 变红并创建告警 issue，原有数据保持不变。
